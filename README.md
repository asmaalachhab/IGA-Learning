# IGA Learning – Plateforme E-learning Académique

Projet full-stack moderne développé avec **Spring Boot, React et MySQL**, inspiré des plateformes e-learning comme Udemy et Coursera.

IGA Learning permet aux étudiants et enseignants de suivre des cours, passer des quiz, obtenir des certificats et gérer leur espace d’apprentissage dans une interface moderne et responsive.

# Installation du projet

## Backend

### 1. Lancer MySQL avec XAMPP

Créer la base :

```sql
CREATE DATABASE learning_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 2. Lancer le backend

Ouvrir le dossier backend dans IntelliJ puis lancer :

```text
LearningApplication.java
```

Backend :

```text
http://localhost:8080
```

---

## Frontend

Dans un terminal :

```bash
cd frontend
npm install
npm run dev
```

Frontend :

```text
http://localhost:5173
```
